API de equivalencias CIE-10 ↔ CIE-11

Una API REST con respuestas JSON para que historias clínicas, sistemas de facturación, de estadística o de vigilancia consulten la CIE-10 y la CIE-11 en español y las tablas oficiales de correspondencia de la OMS entre las dos. Está versionada en /api/v1, documentada con OpenAPI 3 y sólo maneja datos de clasificación.

Reglas de uso

No envíe datos de pacientes. La API sólo recibe códigos o texto de búsqueda; el lote rechaza cualquier campo que no sea sentido, codigos o sin_sugerencias. No se guarda el contenido de las consultas: sólo contadores agregados por ruta y día.

Hay un límite de pedidos por IP (cabeceras X-RateLimit-Limit y X-RateLimit-Remaining; al pasarse, 429 con Retry-After). Las respuestas traen ETag y Cache-Control: los datos sólo cambian cuando cambia la versión (X-Datos-Version). Los errores son JSON con error.codigo y error.mensaje.

Las equivalencias son las de las tablas oficiales de la OMS; no reemplazan la validación clínica ni de codificación. Cuando no hay correspondencia oficial, la respuesta puede traer sugerencias_automaticas: son coincidencias de texto calculadas por este servicio, separadas y rotuladas como no oficiales.
